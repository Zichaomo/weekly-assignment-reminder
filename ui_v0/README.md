# 每周作业提醒 · 界面演示（第二轮）

此目录保留接入前的静态原型。当前控制台位于 `data/ui/`，部署与日常操作见 [项目 README](../README.md)。

纯静态 HTML / CSS / 原生 JS，没有构建步骤，也不连接后端。所有业务操作只展示界面，最后一步会提示「界面演示，后续接入」。

## 目录

```
weekly-homework/
├── index.html        页面结构与所有对话框标记
├── css/
│   ├── app.css       首页样式（第一轮，未改动）
│   └── panels.css    第二轮：对话框、名单、表单、裁剪
├── js/
│   ├── data.js       虚构演示数据（作业、课程表、三个名单）
│   ├── app.js        首页交互：选择作业、搜索、双群预览、提示条
│   └── panels.js     第二轮：课程管理、手动作业、图片查看与裁剪
├── img/homework.png  示例手写作业图
└── package.json      仅包含启动脚本，无依赖
```

## 依赖

运行时通过 CDN 加载，无需安装：

- Lucide 图标 `lucide@0.460.0`（unpkg）
- Google Fonts：Noto Sans SC、Noto Serif SC

对话框使用浏览器原生 `<dialog>`，提示条使用原生 Popover API（Chrome 114+、Safari 17+、Firefox 125+）。

## 启动

任选其一：

1. 直接双击 `index.html` 用浏览器打开。
2. 本地静态服务（推荐）：

```bash
npm start          # 等同于 npx --yes serve .
# 或
python3 -m http.server 8080
```

## 本轮新增界面

- 管理 → 课程管理：课程黑名单 / 测试黑名单 / 选修课名单三个标签页，搜索、加入、移出、确认，选修课页可按编号或名称添加。
- 添加作业：表单面板（科目、标题、截止日期时间、备注）。
- 选中手动作业（大学英语 · 单元练习）：显示编辑、标记完成、删除，隐藏平台正文操作。
- 选中「复变函数 · 第八周习题」：显示作业图片，可查看原图与打开静态裁剪面板。
