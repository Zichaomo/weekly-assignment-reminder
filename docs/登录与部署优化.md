# 登录与部署优化

更新日期为 2026-11-10。面向 Windows 本地部署，兼顾迁移到其他电脑和日常自用体验。

## 已完成

| 方向 | 当前结果 |
| --- | --- |
| 独立 Python 环境 | 启动器默认使用 Python 3.14 的标准用户安装目录，CLI 注册任务及后台子进程跟随入口解释器。既有每周任务已完成迁移。 |
| 登录成功判定 | 登录、会话检查及抓取共享北化在线页面证据。空白页、门户页及单独票据保持待登录，保存会话前再次核验。 |
| 单账号管理 | 控制台支持录入、修改、移除、显式导入 Edge 凭据和登录检查。账号密码采用当前 Windows 用户 DPAPI 加密，修改后要求重新认证和检索。 |
| 企微推送管理 | 控制台管理班级渠道、主用、测试、正式备用及个人地址，支持留空保留、显式清除、原子保存与版本冲突检查。 |
| 首次部署指引 | setup.bat 安装依赖并打开控制台，空白配置自动显示环境、账号、推送和课程初始化指引。 |
| 管理菜单 | 按账号与推送、课程与内容、系统与维护分栏。部署指引采用用户选定的固定底色、左对齐样式，窄窗口使用分组双列。 |

## 验证范围

- 隔离回归覆盖加密保存、凭据优先级、会话异常、并发互斥、配置保留及首次部署。
- 离线 Edge 验证覆盖空白配置、真实隔离后端持久化、十个管理入口和视口可见性。菜单的普通底色及居中方案留作本地预览。
- 本机已有会话的真实平台只读检查返回 LOGGED_IN，会话文件指纹核验通过。
- 具体测试数量、历史实测和验证边界集中记录在 [验收记录](验收记录.md)。
